# V0.3 发布说明

发布定位：确定、可测试、可审计的第一层几何仿真与工程资格评估工具，不代表生产级安全认证或厂商负载认证通过。

## 本版完成的工作

- 增加基于 URDF/FK 真实关节轴线的空间惯量、重力矩和腕部轴向惯量计算。
- 增加负载感知 IK 资格评估，确定性搜索腕部滚转、抓取法向和多个 IK 种子，并保留最佳/次佳姿态与逐轴失败原因。
- 增加 FANUC 厂商证据适配器；在公开资料缺少完整参考系定义和负载—质心图时保持 fail-closed。
- 增加工具质量 5/6/7/8/10 kg 配置、25 kg 纸箱资格案例、车厢横截面输入和统一机器人腕部限制配置。
- 增加确定性 Monte Carlo 周期模型及 900 箱/小时目标的 NORMAL 周期预算计算。
- 增加负载包络、轻量横截面筛查、周期分析和一键技术评估套件。
- 完整 PyBullet 横截面研究改用统一腕部限制来源，支持按安装位并行扫描和最佳安装位独立分支审计。
- 为 `URDFRobot` 增加公开的 `joint_axis_frames()`，负载计算不再根据法兰坐标标签猜测腕部轴。

## 工程整理

- 从版本库移除约 35 MB、100 个历史 `outputs/` 文件，仅将一份代表性演示保留在 `docs/images/`。
- 删除本地约 360 MB 的可再生 `outputs/` 与 `results/`，并将两者加入忽略规则。
- 删除 9 个阶段性搜索/修补配置，以及 9 个一次性调试、迁移和版本化结果生成脚本。
- 删除编辑器专用文件和测试/构建临时目录。
- 补充 `.gitmodules`，修复 KUKA KR 50 R2500 gitlink 无法从新克隆还原的问题。
- 将横向输送带后缘移至机器人基座/J2 保护包络外 300 mm，并保持距最近纸箱 200 mm。

## 关键证据语义

- 公开 FANUC 数值可用于工程参考筛查，但不自动等价于完整厂商负载图认证。
- 已知负载、关节、碰撞或脱垛失败是硬失败。
- 未执行或缺少可追溯来源的检查保持 `NOT_EVALUATED`。
- 轻量横截面工具不会把只通过半径/边界筛查的点标记为任务可达。
- 周期模型的事件概率和时长仍是 `ENGINEERING_ASSUMPTION`，需要生产日志标定。

## 发布验证

- 全量回归：`162 passed`。
- 默认核心演示：本次 Windows 开发环境端到端运行 2.06 秒，满足五秒预算。
- 一键资格评估：成功生成 450 行负载结果、3 组各 2585 格横截面筛查和 100000 样本周期统计。
- 当前默认资格结论为 `NOT_QUALIFIED`：10 kg 工具加 25 kg 纸箱的 18 个尺寸/抓取组合均触发已知腕部力矩或惯量风险；公开负载—质心图仍为 `NOT_EVALUATED`。
- 当前周期工程模型在 3.2 秒 NORMAL 周期下给出约 1088.4 箱/小时；达到 900 箱/小时所需的 NORMAL 周期上限约为 3.892 秒。该结果不是生产实测承诺。

## 兼容性

- Python 包版本由 `0.2.0` 更新为 `0.3.0`。
- 生成结果不再随 Git 提交；调用方应显式保存所需的 `outputs/` 或 `results/` 证据包。
- KUKA 资源需要递归克隆子模块，或在已有克隆中运行 `git submodule update --init --recursive`。

## 已知边界

- 尚无可追溯的 FANUC M-20iD/35 完整负载—质心图或 ROBOGUIDE 证据。
- 工具质量、质心和惯量仍以提供的 STEP 均质工程模型为基础，法兰钟向为临时定义。
- 轻量可达性筛查不执行完整姿态 IK、扫掠碰撞和轨迹动力学。
- 完整横截面研究是确定性密集离散采样，不构成解析连续碰撞证明。
- 周期事件参数尚未用生产日志标定。
