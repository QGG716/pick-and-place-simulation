# V0.4 发布说明

## 发布定位

v0.4 将工程的主评估对象从历史 FANUC M-20iD/35 基线扩展到 FANUC M-710iD/70，并重新定义物流车厢卸货的传送带模型、脱垛策略、完整任务判据和统计输出。

本版本废除固定 250 mm 直线退避假设。v0.3 报告中由该假设得到的任务覆盖率、不可达面积和连续卸货结论不得继续作为 v0.4 结论。

## 机器人与证据

- 新增 `fanuc_m710id_70` 规范机器人身份、运行配置、资格案例和工具配置。
- 新增由所提供 ROBCAD/CAD 和 FANUC 演示资料建立的第一层工程 URDF/SRDF。
- 关节轴线、零位、限制、最大速度、额定负载、腕部力矩/惯量及负载图来源均记录在配置和 `SOURCE.md` 中。
- 碰撞几何仍是 CAD 外形的保守工程代理，不是厂商发布的精确碰撞模型。
- 厂商资料未提供完整连杆质量、质心、惯量和驱动允许转矩；精确逆动力学继续为 `NOT_EVALUATED`，没有填入假设值。

## 动态脱垛策略

- 新增 `unloading_sim.depalletizing` 独立核心模块。
- `BoxNeighborhoodState` 使用 OBB 世界投影重叠与表面间隙识别：
  - `left_neighbor`；
  - `right_neighbor`；
  - `top_neighbor`；
  - `bottom_support`；
  - `front_clearance`；
  - front/left/right/top 暴露面。
- 双侧受限时生成正面最小直线脱垛候选；脱垛距离由增量几何扫描和二分细化得到。
- 单侧开放时优先从开放侧吸取，并允许直接侧向进入自由空间；失败后才回退正面抓取。
- 双侧开放时同时生成 front、left、right、top 候选，顶部抓取不再拥有特殊优先级。
- 完整候选按带载 TCP 路径、几何脱垛距离、关节运动、碰撞风险、奇异性、关节限位裕量、交接距离和腕部裕量评分。

## 独立 L 形传送带

- 传送带不再作为底盘刚性 link，不计入底盘质量或机器人负载。
- 传送带保持与底盘相邻的参数化几何拓扑，并在与世界一致的 `+X/+Y/+Z` 坐标中建立明确变换。
- 新增 `conveyor_extension` 和 `conveyor_z` 两个运动自由度。
- 前端最大伸出位置按目标/箱堆外表面的 20 mm 几何净空计算，而不是按箱体中心估算。
- 接收面最低为车厢底面上方 200 mm，最高为当前最上层剩余箱体底面下方 15 mm。
- 预定位过程检查传送带与车厢、箱体、机器人和工具的碰撞。
- 真空释放由交接状态机门控：箱体进入支持区域且交接姿态无碰撞后才能释放。

## 新任务语义

完整几何任务至少包含抓取姿态、IK、关节限制、奇异性、机器人/工具碰撞、吸附面、脱垛路径、脱离箱堆、传送带预定位、带载交接路径、支持区域和交接碰撞检查。

负载资格不会短路运动规划，结果拆分为：

- `GEOMETRICALLY_REACHABLE`；
- `PAYLOAD_QUALIFIED`；
- `QUALIFIED_TASK`。

这样即使 42.5 kg 箱体的 FANUC 负载—质心图判定失败，仍可独立评估几何和运动学覆盖。

## 验收结果

发布验收使用 0.30 m 网格扫描 2.3 m × 2.7 m 横截面，并分别计算 600×400×300 mm 和 400×600×300 mm 箱体朝向。覆盖率只统计完整位于车厢截面内的 104 个有效朝向样本。

| 指标 | 结果 |
| --- | ---: |
| grasp coverage | 78.846% |
| extraction coverage | 63.462% |
| conveyor handoff coverage | 50.000% |
| full geometric task coverage | 50.000% |
| payload-qualified coverage | 0.000% |

旧版完整任务覆盖率为 25.609%；新定义结果增加 24.391 个百分点。由于传送带、脱垛和任务语义均已变化，该差值只用于工程对比，不代表单参数因果实验。

抓取成功统计（横截面成功样本和连续场景合计）：

- front：33；
- left：0；
- right：0；
- top：21。

双侧受限箱的最小正面直线脱垛距离 P50/P95 均为 0.620 m。400 mm 深箱的回归值为 0.420 m，证明该距离不是另一个固定常数。

动态传送带配合当前安全清堆折线后，成功连续样本的平均带载 TCP 路径相对固定 extension=0、Z=0.20 m 基线增加 0.221 m。本版本保留该负结果，没有为了得到“缩短”结论而删除安全清堆段。

连续卸货结果：

| 场景 | 几何卸出 | 负载资格通过 |
| --- | ---: | ---: |
| regular | 0 / 40 | 0 |
| random_seed_71071 | 2 / 27 | 0 |
| random_seed_71072 | 0 / 32 | 0 |
| random_seed_71073 | 0 / 30 | 0 |

横截面运动规划主要失败是 `NO_IK`。完整 42.5 kg 案例的第一项独立硬失败仍为 `PAYLOAD_CG_FAILED`。

## 负载包络

`payload_envelope.csv` 覆盖：

- 箱体质量 5–45 kg，并包含当前 42.5 kg 案例；
- 箱体深度 200–700 mm；
- TCP 100、150、200 和 250 mm；
- 工具质量 10、15 和 20 kg；
- 工具轴向质心 100 mm 和当前约 149.8 mm。

20 kg 工具与 42.5 kg、600 mm 深箱的组合质量为 62.5 kg，组合质心约 0.422 m，当前保守 70 kg 曲线判定 FAIL。按同一曲线反算的 TCP 上限约 0.037 m，100 mm TCP 方案仍失败。减轻工具并不必然改善组合质心，因为较远箱体质量的权重会相对增加。

## 安装位扫描

第一层离散 `base_x × base_z` 扫描给出：

- 推荐 base X：-0.500 m；
- 推荐固定 base Z：0.700 m；
- 当前最优带宽最低/最高 base Z：0.700/0.700 m；
- 对应离散建议行程：0.000 m。

该结果使用 X=0.20 m、Z=0.30 m 步长和有限探针。零行程只表示本次离散候选中单一高度最好，不是连续优化或制造定版结论。

## 后续优先级

1. 调整末端/抓取方向的有效负载中心，或选择负载包络更大的机器人，并用 FANUC 负载设定软件或 ROBOGUIDE 复核。
2. 为侧面抓取增加安全滚转、多起点 IK 和局部 SE(3) 连接候选，优先降低 `NO_IK`。
3. 加密 base X/Z 与传送带几何扫描，验证粗网格安装建议。
4. 获得真实连杆惯量、驱动转矩和吸具剥离/泄漏数据后再进行动力学与真空资格认证。
