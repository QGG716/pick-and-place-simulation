# V0.3.1 发布说明

## 定位

v0.3.1 是机械臂更换前的软件基线清理，不是一次仿真或工程资格复评。本次没有运行卸垛仿真、可达性研究、横截面研究、周期仿真、PyBullet、Isaac Sim 或资格套件，也没有生成新的 `outputs/`、`results/` 或报告结果。

因此，v0.3 的既有数值、图片和结论保持原样，只能作为 FANUC M-20iD/35 历史基线。它们不构成下一款机械臂的可达性、节拍、负载或安全结论。

## 软件基线变更

- Python 包版本更新为 `0.3.1`。
- 规范机器人 ID 为 `fanuc_m20id_35`；`fanuc_m20id35` 作为旧数据输入别名兼容，输出统一写规范 ID，未知型号 fail-closed。
- 新增 10 kg 工具主配置 `configs/tools/unloading_gripper_10kg.yaml`；默认工具配置仅作为别名引用它，不再复制质量、质心、惯量或 TCP。
- 运行配置与资格案例分别引用同一个工具主配置。工具不再被视为 FANUC 专属数据，可由后续机器人配置复用。
- 8 kg 工具文件明确保留为历史缩放工程模型，不是当前默认配置。
- 报告上下文由实际解析后的机器人、工具和结果构建，记录规范型号、工具名称、质量、TCP、配置绝对路径、SHA-256、状态和原因，不再在报告层写死型号或失败计数。
- 轨迹缓存身份至少包含机器人型号、运动学哈希、工具名称、工具质量、工具配置哈希和 TCP；身份缺失或不匹配时拒绝复用。
- `pytest` 默认路径包含仓库根目录，可在干净检出中导入 `studies`。默认测试排除仿真、慢测试和重型后端 marker。

## 工具证据边界

当前默认工具总质量为 10 kg。质量、质心和惯量来自所给 STEP 实体的均匀密度工程估算，状态仍是 `ENGINEERING_MODEL` / `NOT_MEASURED` / `NOT_EVALUATED`；本次清理没有把任何字段提升为实测值或厂商认证值。

## 验证边界

本版本只执行静态检查和默认轻量单元测试。后续机械臂接入后，应先建立独立机器人配置与运动学证据，再显式引用同一工具配置；只有在新的仿真和资格流程获准并完整执行后，才能发布该机械臂的新工程结论。
