# 发送路径自适应审计：步长上界推导（实时化第 6 步）

适用范围：配置 `sent_path_audit: ADAPTIVE`（缺省 `SAMPLED`），只对现场单箱范围（`PHYSICAL_SINGLE_CARTON`）生效。M710 和空载入口不变。依据 AGENTS.md 2026-11-16 §3b。

## 1. 被检查的对象与现行规则

被检查的是实际发送的分段五次曲线 `q(t)` 的几何路径。

`controlled/trajectory.py prepare` 在曲线上取一串探测状态（`collision_path`），取法是：相邻两点之间，任意物体对的相对位移上界不超过 1 mm，即 `4R·Σ_j V_j·Δt ≤ 1 mm`。其中：
- `R` 为模型到达半径加载荷到达半径；
- `V_j` 为第 `j` 关节在多项式导数零点处取得的精确最大速度。

worker 的 `checkPath` 对每两个相邻探测状态之间的线段再按关节空间线性插值加密，逐个检查（下称 **SAMPLED 采样点**）。每个采样点都要求每个物体对的距离 ≥ 该对限值（2.4 mm），并满足关节范围和现场工作范围。

统一的时间缩放 `s` 只是把 `q(t)` 换成 `q(t/s)`，几何路径不变，探测点的间距规则也不变（单元测试 `test_probe_states_bound_any_pair_displacement_by_1_mm`）。规划流程里 ×1.1 到 ×2 的逐级放慢都发生在审计之前，所以每段只审计一次。几何一旦变化（重新规划），必须重新审计。

**连续保证（SAMPLED 与 ADAPTIVE 相同）**：曲线上任一状态都夹在两个相邻探测状态之间，与较早那个探测状态相比，物体对的相对位移不超过 1 mm；而探测状态本身满足 ≥ 2.4 mm。所以任意状态的间隙 ≥ 2.4 − 1 = **1.4 mm**。前提是 `R` 和 `V_j` 正确，浮点误差另计。

## 2. ADAPTIVE 的做法：只跳过可证明通过的采样点

ADAPTIVE 走的是**与 SAMPLED 完全相同的采样点序列**，逐个处理：

1. 第一个采样点，以及每个不能证明通过的采样点，都用原来的精确检查（EXACT 或 TWO_LEVEL，判定不变），称为锚点。
2. 锚点通过后，计算一组约束 `(m_i, c_i)`：`m_i` 是距离余量的下界，`c_i` 是每个关节的位移系数，定义见第 3 节。
3. 之后的采样点 `q`，若关节范围通过，并且对每个约束都有

       m_i − Σ_v c_{i,v} · |q_v − q^anchor_v| ≥ ε（ε = 1 µm）

   就证明它在每个物体对上都不低于限值、仍在现场工作范围内，跳过；否则做精确检查，并成为新锚点。

结论：
- 被跳过的点都已证明通过。任何会被 SAMPLED 拒绝的采样点都不可能被跳过，所以一定会被精确检查到。
- 因此 ADAPTIVE 与 SAMPLED **判定逐个相同，首个失败的采样点、物体对、距离也相同**。ADAPTIVE 通过 ⇒ SAMPLED 通过；SAMPLED 拒绝 ⇒ ADAPTIVE 在同一采样点拒绝。
- 离障碍远时余量大，一次跳过很多点；距离下界接近 2.4 mm 时余量趋于 0，自动退回逐点检查，即现行密度。

## 3. 位移上界（力臂界与两个物体同时运动）

**单个物体的力臂界。** 设点集固定在连杆 `L` 上，到 `L` 坐标原点的距离不超过 `ρ`。从 `L` 沿运动链向根部走，设 `reach` 为点集到当前连杆坐标原点的距离上界，初值为 `ρ`：
- 遇到规划组的转动关节 `j`，且当前连杆是它的子连杆：子连杆坐标原点在 `j` 的轴上，所以点集上任一点到轴的距离 ≤ `reach`，速度 ≤ `reach·|q̇_j|`。于是取力臂 `L_j = reach`。
- 遇到移动关节：其下所有点都恰好平移 `|q̇_j|`，取 `L_j = 1`。
- 每向上走一级，`reach` 加上该关节原点平移的长度；若是移动关节，再加上它的最大行程。

这样 `reach` 对所有构型都成立。沿关节空间直线 `q^anchor → q` 积分，点集上任一点的位移 ≤ `Σ_j L_j·|Δq_j|`。

**两个物体同时运动。** 刚体组是由固定关节连在一起的连杆和附着载荷。设两个组的上游关节集合为 `S_A`、`S_B`，它们的共同部分只让两者整体刚性运动，不改变它们之间的距离。在最深公共祖先的坐标系里：
- A 只因 `S_A \ S_B` 中的关节运动；
- B 只因 `S_B \ S_A` 中的关节运动。

所以这一对的距离变化 ≤ `Σ_{j∈S_A\S_B} L_{A,j}|Δq_j| + Σ_{j∈S_B\S_A} L_{B,j}|Δq_j|`。若一方静止，它的集合为空，退化为单个物体的情形。

**约束的组织**，每个锚点计算一次：
- **每一对运动刚体组一个约束**：系数如上；余量取这两个组之间所有物体对 `(距离下界 − 限值)` 的最小值。
- **每个运动刚体组对全部静止物体一个约束**。
- 每对的距离下界取下列三者中的最大值：
  - 物体包围球的距离（第 5 步的代理）；
  - 保守 AABB 的距离；
  - 本锚点精确检查算出的 FCL 距离。ADAPTIVE 时 FCL 的初值放宽为 `限值 + D_cap + 1 mm`，返回 `min(真实距离, 初值)`；低于限值的距离与原来完全一样，所以判定不变。
- 余量截断在 `D_cap = 0.05 m`，它限制单次跳过的最大位移。远处的物体对用组包围球和静态层次包围直接取 `D_cap`。
- 同一刚体组内部的物体对，相对位姿恒定，锚点通过就处处通过，不建约束。

**现场工作范围。** 每个连杆的世界轴对齐包围盒，以及载荷角点，到边界的余量作为一个约束。系数用这个点集（连杆包围盒的角点、载荷角点）的力臂界；边界是固定平面，只算一侧运动。轴对齐包围盒的每个面，移动量不超过其角点的移动量。

单元测试（`m710_clearance_test adaptive`）：
- 在移动关节 + 转动关节链和三转动关节臂上，随机构型对共 12000 个物体位移都不超过上界；
- 证明可跳过的采样点（10342 个）全部通过精确检查；
- 600 条随机路径，ADAPTIVE 与 SAMPLED 的判定和首个失败逐项相同；
- 擦碰和穿入的柱子，两种方法都拒绝。

## 4. 适用范围：接触、密封、支撑

`SingleCartonContact` 中与位姿有关、但不是间隙的条件，不能用上面的界证明：
- 接触阶段：法向和杯唇穿入；
- 带支撑物：载荷对支撑面的穿入。

所以 ADAPTIVE 只用于**没有接触许可、没有支撑物**的段，按条件判断，不按阶段名。接触段和带支撑段始终用 SAMPLED；worker 收到这类请求时返回 `SENT_PATH_AUDIT_SCOPE_INVALID`。

符合条件的段：
- 不带载（接近）：只剩现场工作范围这一项，已在约束中处理。
- 带载、无支撑（返回）：固定附着下的密封、覆盖、法向条件与状态无关（`target⁻¹·flange_cad` 为常量）。锚点通过即处处通过。

## 5. 证据字段

worker 回复 `clearance.sent_path_audit` 包括：方法、采样点数、精确检查数、跳过数、锚点数、最小距离下界、最小工作范围余量、`D_cap`、ε、约束计算耗时和证明耗时。

planner 在每段的 `collision_result.sent_path_audit` 记录：
- `audit_method`、探测状态数、采样点数、精确检查数、跳过数、`D_min`；
- `continuous_swept_proof`：通过时为 `BOUNDED_DISPLACEMENT_1_4_MM`，SAMPLED 与 ADAPTIVE 相同，含义见第 1 节；拒绝时为 null。

原生检查器自身的 `continuous_swept_proof` 仍为 false，因为单个检查器只判定各个状态，不掌握探测点的间距。
