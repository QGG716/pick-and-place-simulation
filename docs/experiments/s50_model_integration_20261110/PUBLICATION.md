# 本次公开分支的资产范围

用户已明确授权将真实 STEP、派生网格、嵌入网格的离线查看器以及官方手册发布到本 feature 分支。本次追加提交按该授权纳入原始 STEP、官方机械手册、七个无损压缩的 `*.obj.gz` 网格包，以及本目录生成版 [viewer.html](viewer.html)。具体文件、哈希和本次验证见 [资产发布验证](asset-publication-validation.json)。

这项用户授权说明本次发布工作的授权范围，**不等于厂家授予再分发许可**。资产的来源、原文件哈希、原有许可或使用说明继续保留；没有将厂家资产标为自行创作、开源或新增授权，也没有据此扩大其使用许可。

此前 [`cff77ce` 代码/报告版](https://github.com/QGG716/pick-and-place-simulation/commit/cff77ce) 只发布了代码、配置、测量和验证报告，未纳入上述完整资产。此前的自动审批因当时授权未明确覆盖原始 CAD/文档而拒绝发布资产；现在用户已补充明确授权。该历史版本的资产缺失拒绝、依赖真实 STEP 的测试跳过行为及已有本地/服务器测试记录保留原样，不回写成当时已发布资产。历史测试与尺寸验证是在具有真实资产的本地或服务器环境中实际运行的；本次追加发布的独立验证另见上述记录。

资产目录为 `assets/robots/huayan_s50_2000/`，完整离线查看器位于本报告目录 `viewer.html`，下载后可直接双击打开。取得本次追加提交后，可在仓库根目录重建查看器；导出器支持直接读取已提交的 `.obj.gz`，不要求先解压：

```sh
python tools/export_s50_model_viewer.py --output docs/experiments/s50_model_integration_20261110/viewer.html
```

如需原始 OBJ，可另运行 `python assets/robots/huayan_s50_2000/pack_meshes.py --unpack`。解压后仍核对原始 OBJ 哈希，不改变 CAD 清单或几何。资产不存在、gzip 损坏或哈希错误时仍明确拒绝，不生成替代模型。

资产发布不改变 **`MODEL_NOT_READY`**。六轴控制器零位、正方向、安装/工具映射和完整碰撞覆盖仍未核定，真实 S50 初态、FK 交叉验证、碰撞验证与单箱原生规划仍为 **`NOT_RUN`**。查看器中的六关节控件继续禁用，静态 CAD 装配不冒充已接入的可运动模型；已有浏览器可视验收状态也不因发布资产而改变。
