## 实际求解与验证

本轮使用现有 URDF DLS IK、RRT Connect 和 Pinocchio/Coal。初态独立求解，没有复制 FANUC 关节角，没有输入旧轨迹。关节临时范围、固定安装映射、原工具及 200 mm 延长段集中在 `configs/robots/huayan_s50_2000_kinematic_sim.yaml`。

新 STEP 的六条关节轴与此前实测链仅有浮点舍入差异，法兰原点和安装面一致；七个可视连杆及主要碰撞网格已重新生成。缺失的两小处网格面沿用已明确标注的历史局部保守补片，不声称新 STEP 的精确覆盖认证。见[来源摘要](../../../assets/robots/huayan/s50_1_kinematic/source-summary.json)。
