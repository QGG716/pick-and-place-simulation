# 临时参数与厂家资料清单

本轮只做单箱运动学仿真。以下缺项不阻断本轮求解，也没有被标记为厂家已验证。

新增两页厂家资料已补充标称值和安装尺寸来源，见[资料解读](manufacturer-supplement.md)。它们没有补齐惯量、力矩、负载包络或控制器映射。

| 项目 | 本轮采用 | 向厂家索取／后续校准 |
|---|---|---|
| 坐标 | 新传 `S50_1.STEP` 装配零位；现有 URDF 右手正方向 | 对应机械与控制器版本的零位图、六轴读数、正方向、J2/J3 耦合说明、DH/URDF、法兰坐标定义 |
| 临时关节范围 | J1/J4/J5/J6 ±360°，J2 ±100°，J3 ±160° | 机械与软件限位、仿真到控制器的 sign/offset 映射 |
| 安装与工具 | 固定轴心 [-1.85, 0.15, 0.90] m；模型绕安装参考 Z +90°；同轴贴合理想连接；原 200 mm 延长段只计一次 | 底座和法兰安装图、孔位／定位销、公差、法兰允许外力／力矩及实际转接件图 |
| 时序 | 0.35 rad/s、0.5 rad/s²；横带升降 0.15 m/s；输送 0.25 m/s；播放默认 1× | 与控制器版本对应的各轴速度、加速度、减速度、负载相关降额；解决已有速度版本冲突 |
| 动力学 | 未执行动力学验证，质量未减轻 | 每连杆质量、重心、完整惯量张量及参考坐标系；关节侧持续／峰值力矩及持续时间、减速比、折算惯量、摩擦参数 |
| 负载 | 工具 20 kg、箱体 42.5 kg，共 62.5 kg | 负载—重心偏距—腕部弯矩—惯量包络；将实际组合参数交厂家书面确认，不能由运动学成功推断负载资格 |
| 碰撞 | 新 STEP 网格、既有两处局部保守补片、原工具组合体；离散基本避障 | BRep、精确网格覆盖、安装制造配合及连续净空认证后置；补片不是新 STEP 精确覆盖证明 |
| 吸取与接收 | 独立杯完整密封环几何，理想保持；明确标记理想落带／输送 | 真空、力、摩擦、落带动力学和实际接触检测 |
| 控制对照 | 无实机连接 | 通信协议、单位、反馈频率、插补、跟随误差、报警；若干组关节读数与实测法兰位姿 |

资料须绑定具体 S50-2000 机械版本、控制器版本和序列号；另索取安装、维护和安全手册，用于后续机械与安全验收。
