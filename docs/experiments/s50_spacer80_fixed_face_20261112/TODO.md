# 临时参数和后续校准

- 构型偏好：按实际 J2→J3 连线在世界 XZ 平面相对竖直方向的倾角判断；朝箱堆 30° 内不加罚，超过后连续加罚。30° 是本轮工程软偏好的暂定分界，不是厂家限位，也不禁止大角度解。
- S50 专用安装：105 mm 短支架 + 80 mm 同轴隔距段；背板距法兰 185 mm，名义压缩吸盘接触面距法兰 252.5 mm。后续确认实际零件尺寸、螺孔、强度及线缆空间。
- 厂家页限位沿用 J1/J4/J5/J6 ±360°、J2 [−190°, 10°]、J3 ±160°。当前 S 系列工程零位、正方向及 S50 控制器映射仍需厂家确认，不把仿真坐标称为控制器已校准坐标。
- 回放使用统一保守速度 0.35 rad/s、加速度 0.5 rad/s²；20 kg 工具、42.5 kg 箱体的账面质量不变。实际惯量、负载曲线、力矩、速度版本及吸附承载能力留待动力学和实机阶段确认。
- 本轮检查真实网格采样状态的明显碰撞及明确连接接触；连续碰撞覆盖、动力学和正式任务验收未在本轮认证。
