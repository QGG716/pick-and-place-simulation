## c00 的具体阻断

正面抓取 IK 可以求出，主要阻断发生在路径碰撞检查：

1. 一支完成接触和预抓取检查，在直线抽离约 **394 mm**、第 17/27 点时，`tool_s50_mount_flange` 与 `s50_link_3` 相交，即短连接安装板碰到小臂。该点 IK 位置误差约 **0.00026 mm**，不能归因于 IK 未求出。
2. 另一支在接触姿态合法，但反向检查预抓取路径时，约 **48 mm** 处的 `s50_link_2` 与 `conveyor_longitudinal` 相交，即上臂碰纵带。该点 IK 位置误差约 **0.0082 mm**。

主流程还实际尝试了同一箱的顶吸姿态，70 次数值 IK 均未收敛。以上是当前有限搜索的结果，不是全局不可达证明。主报告末尾的 `last_collision` 只代表最近碰撞记录；查看器提供的两个红色候选分别对应上面两条实际失败路径。

## 启动命令

在已有 Pinocchio/Coal 环境、当前分支重新尝试完整初始场景：

```sh
python tools/run_s50_face_kinematic_sim.py --config configs/robots/huayan_s50_short105_kinematic_sim.yaml --gaps .1 --output outputs/s50_fixed_face
```

默认只使用当前配置的固定间距，不再自动切换到 200/300 mm。失败时也导出真实有效前缀的 `gap_100/viewer.html`。已有本轮 [viewer.html](viewer.html) 为单文件离线回放，无需服务器。
