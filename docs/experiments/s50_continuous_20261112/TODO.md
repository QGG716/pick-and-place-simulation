# 本轮临时约定及后续校准

- CAD 装配零位、URDF 右手方向；临时范围 J1/J4/J5/J6 ±360°、J2 ±100°、J3 ±160°。向厂家核实控制器零位、正方向和限位映射。
- 固定安装参考与模型 Z+90° 映射不变；原工具同轴贴合理想连接，200 mm 延长段只计一次。后续核对孔位、定位、制造公差和实际 TCP 标定。
- 新偏好：J2 −100°～+40°，小臂实际世界倾角绝对值 ≤30°，J4→J5 朝 −Z；均为软偏好。J3 的符号及变化趋势不再参与偏好。
- 横带目标为当前箱底减 100 mm，受 550～1500 mm 限制；本箱限高后仍有约 600～620 mm 间隙。落带和输送为运动学动画。
- 仿真速度／加速度 0.35 rad/s、0.5 rad/s²，升降 0.15 m/s、输送 0.25 m/s；后续核实版本一致的厂家时序参数。
- 后置：逐连杆质量／重心／完整惯量、持续及峰值关节力矩、负载—偏心—弯矩—惯量包络、严格碰撞覆盖与连续净空认证。

厂家两页资料的标称负载为 50 kg，当前原工具加箱体为 62.5 kg；运动学通过不补足真实负载资格。详见已有[两页资料解读](../s50_step1_kinematic_20261112/manufacturer-supplement.md)及[完整索取清单](../s50_step1_kinematic_20261112/TODO.md)。本轮未改动任何厂家／动力学验证布尔值。
