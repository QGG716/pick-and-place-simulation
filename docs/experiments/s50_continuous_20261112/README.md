## 这次修改与实际结果

- **连接件显示**：原工具的两块加长侧板和法兰连接板保持原尺寸与变换，改为不透明橙色、双面显示并加轮廓。提供“连接件近景”；没有补造虚拟长度。
- **构型软偏好**：J2 优先 −100°～+40°；小臂采用 **J3 轴心到 J4 轴心的世界方向**，相对水平面夹角的绝对值优先 ≤30°；J4→J5 优先朝世界 −Z。J3 角度正负及变化趋势已从偏好中移除。原关节合法范围不变。
- **横带高度**：目标为箱底减 100 mm，裁剪到 550～1500 mm。当前顶层箱箱底 2100 mm，目标 2000 mm，实际升到上限 1500 mm，初始接收间隙 600 mm；20 mm 分离抬升后释放名义落差约 620 mm。不能把限高后的间隙称为 100 mm。
- **带载路径**：在空载预抓取处先升横带，再接近、吸取。20 mm 分离、直线抽离至箱体完全脱离箱堆、短弧进入横带接收区，使用上一点解作为下一点 IK 种子。通过实际求得的关节节点构造共享速度的连续曲线，再检查所有输出状态；抽离和转运之间没有停顿事件，带载段不再使用 RRT 绕行。
