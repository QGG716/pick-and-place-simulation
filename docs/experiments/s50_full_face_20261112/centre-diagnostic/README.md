# 100 mm 布局：顶层中间箱直线抽离诊断

双击 `diagnostic-viewer.html`，不需要网络或 ROS。查看器包含原 S50 CAD、原吸具和 200 mm 延长段、全部 40 箱及原装置几何。默认显示大臂与横带的碰撞候选。

- **① 大臂撞横带**：查看 `s50_link_2` 与高 1500 mm 的横带相交的位置。支持全景、碰撞特写和连接件近景。
- **② IK 内侧边界**：查看 J5 轴心的实际位置、失败点的目标位置，以及箱子刚完全抽出时的目标位置。半透明圆柱是运动学必要不可达区，不是新增障碍物。
- **从吸取点播放**：回放这个分支的实际逐点 IK 有效前缀；可暂停或拖动。到最后有效点停止。
- **显示失败候选**：单独显示被拒绝的关节状态。此状态没有被作为合格轨迹执行。

## 结论

固定目标 `carton_l07_c02`，正吸方向固定，先抬升 20 mm，再沿世界 −X 直线抽离。基座安装参考 `[-1.25, 0.15, 0.90] m`，横带前沿 X = −0.10 m，表面高度 1.50 m。没有移动箱堆、改变工具长度或移走旁箱。

| 查看器分支 | 首个拒绝记录 | 原因 |
|---|---:|---|
| 1、5、6 | 抽离约 493 mm | IK 未满足位置 0.04 mm、姿态 0.0001 rad 阈值；所需 J5 位置进入结构内侧不可达区 |
| 2、3、4 | 抽离约 469 mm | IK 成功；大臂 `s50_link_2` 与横带相交 |

这些距离是离散检查中的首个拒绝记录，不是连续路径首次接触的精确位置。碰撞分支的前一有效记录约为抽离 444 mm。独立重查确认相交来自本次 STEP 的原始大臂网格 `s50_link_2_0`；局部保守补片 `s50_link_2_1` 没有相交。

IK 失败还用实际运动链做了独立几何复核：J2、J3、J4 的平行轴使 J1→J5 向量在 J2 轴方向的投影恒为约 253.9998 mm，因此 J5 到 J1 轴线的水平半径不能小于这个值。原工具连接下，J5 到吸盘接触点的同轴距离为 552 mm（134.5 mm 腕部加 417.5 mm 既有工具接触变换）；没有增加工具长度。

对正吸方向 +X、中间箱 Y≈0、100 mm 布局，直线抽离约 493.022 mm 即到达该必要边界。箱深 600 mm，刚完全抽出时要求 J5 水平半径约 179.176 mm，小于 254 mm。因此，这条固定朝向的完整直线抽离本身不成立，不能靠换种子或调整 J2 解决。

原 180 次迭代的三次 IK 提前停止残差为 0.12–0.18 mm；降低阻尼并追加迭代后，它们前进到后续的约 493 mm 点，仍失败。查看器使用追加迭代后的记录，保留原失败报告。
