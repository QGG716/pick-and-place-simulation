复用已有 `S50.STEP`、七个部件和六条实测轴线，见[既有 CAD 模型核对](../s50_cad_motion_20261110/README.md)。新入口单独生成临时范围 URDF；核心、Pinocchio 和查看器使用同一 CAD 定义。CAD 装配姿态为仿真零位；模型基座相对固定安装参考绕 Z +90°、无平移，使 J1=0 的主要摆动平面朝向箱堆。工具安装参考 +X 对齐法兰 +Z，+Y 对齐法兰 +Y，无新增平移。法兰至压缩接触面 417.5 mm，至原虚拟 TCP 450 mm；二者各司其职。

非机器人实体、尺寸、位姿、行程及工具固有几何保持一致。Windows 与 Linux 原始指纹分别为 `a315bcfc…bc1a1`、`13f1bbd2…9d950`，与前轮逐字段核对的两份指纹完全相同；它们仅有六个剪叉派生角度末位浮点差异，实体几何全部相等。保留[既有跨平台比较](../s50_task_collision_20261111/platform-layout-comparison.json)，不伪造原始指纹一致。HTML 在服务器按本轮原始场景指纹生成。新完整仿真场景指纹单独记录于 `cycle.json`。

## 实际过程

初态 q_sim 约 `[5.471, 26.178, 107.439, -133.617, 84.529, 0.000]°`，独立求解接触目标 `[-0.2, 0, 1.5] m`；没有复用 FANUC 关节数值。

| 阶段 | 实际方法与结果 |
|---|---|
| 初态、预抓取 | 多种数值初猜 IK、关节路径，通过 |
| 接近、20 mm 分离、抽离 | 逐点 IK，上一点作为种子，通过 |
| 吸取 | 原完整密封环检测，72 杯中 48 杯发出有效指令；无承载力资格声明 |
| 升带、转运 | 先在高位抽离姿态升带至 1.3 m，再执行带箱关节路径，通过 |
| 释放、落带 | 箱心约 [-1.05, -0.4, 2.1] m，完整投影进入横带；检查整段落箱通道，名义下降约 650 mm，通过 |
| 退出、出料避让 | 沿吸取法向反向退出 120 mm，再关节规划回本轮高位抽离姿态，通过 |
| 输送、降带、返回 | 原 -Y 横带 / -X 纵带理想输送；箱体整个包络越过 X=-3.2 m 后降带，再返回初态，通过 |

最终成功尝试有 **126 次 IK、2,259 个回放状态、4,844 次状态碰撞检查、375,620 次窄相对象对查询**。每个实际运动插值状态均检查临时关节范围和基本碰撞。记录时长约 201.793 s；统一工程时序不是厂家节拍。最大记录关节速度 0.349862 rad/s，最大相邻关节增量 0.041415 rad；离散检查不等于连续净空证明。

核心与 Pinocchio FK、一整条记录的核心与独立 JavaScript FK 一致，矩阵最大误差低于 `1.2e-15`；吸附期间箱体相对工具固定，释放后解除跟随，返回误差低于 `1e-15 rad`。最终箱体最大 X 为 -3.201 m。新增接入测试服务器 3/3 通过，本地轻量测试 2 通过、1 项 Coal 测试因依赖缺失跳过；FANUC 官方模型加载回归通过。

失败记录没有删除：先后排除了高位反向释放 IK 未找到解、落箱经过小臂、横带升降扫过肩部、停在接收位阻挡出料、横带升高时原初态与横带相交等情况。早期前两次尝试存在 Coal 负相交值解释错误，已明确作废其碰撞接受结果；第三次起修复并增加真实网格回归。有限数值搜索失败不代表结构不可达。
