# 本轮临时约定与后续校准

本轮使用用户明确授权的运动学仿真配置；以下事项不阻断本轮计算，也未被改写为“厂家已验证”。

| 项目 | 本轮采用 | 后续校准 |
|---|---|---|
| 零位与符号 | 实测 CAD 装配零位、URDF 右手方向 | 厂家参考姿态六轴读数、正转方向，建立控制器 sign/offset |
| 仿真范围 | J1/J4/J5/J6 ±360°，J2 ±100°，J3 ±160° | 与真实机械限位逐轴映射；当前值不能用于实机控制 |
| 基座坐标 | 固定安装参考不变；模型基座相对参考绕 Z +90°，无平移 | 实际安装定向图；本轮不搜索底座位置或安装旋转 |
| 工具连接 | 同轴、安装面贴合，原工具安装 +X 对应法兰 +Z，+Y 对应法兰 +Y | 实体转接件与制造级装配图；无额外虚拟长度 |
| 时序 | 0.35 rad/s、0.5 rad/s²，保守分段平滑；输送 0.25 m/s | 厂家速度版本、控制器时间参数化；不用于节拍排名 |
| 碰撞 | CAD 原网格及已有补片、完整环境、原工具组合体；离散相交检查 | 残余 BRep、56 个加载三角形差异、严格覆盖及连续净空认证 |
| 设计接触 | 固定 base–plinth；相邻关节轴附近半径 180 mm、轴向半长 360 mm 的临时连接区；仅 link 6 与自有工具 | 逐机构的制造级接触范围核实。活动连杆对支座、环境仍检查 |
| 吸附与下游 | 原 72 杯几何完整密封环、理想保持；名义落带和理想输送 | 真空、力、动力学落带与接触传感器验证 |

工具 20 kg、箱体 42.5 kg 保持不变，总计 62.5 kg；已有资料记录 S50 额定载荷 50 kg。本轮几何运动学结果不构成负载资格。惯量、力矩和控制器通信均未验证；没有运行 Isaac 或全 40 箱搜索。

浏览器验收缺项：本轮浏览器组件因无法可靠识别 Windows Edge 当前网址而停止操作。离线 HTML 的脚本和 FK 可独立核对，但不能据此声称实际浏览器验收通过。关键帧 PNG 是真实轨迹的 CAD 网格渲染，明确标注为非浏览器截图。
