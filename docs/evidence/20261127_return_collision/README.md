# 2026-11-27 带载配置下带箱返回段碰撞与释放点的可视化

数据：上一轮用 `single_carton.field_continuous_loaded_20261126.json` 对 6 条现场记录做的生产计划入口重放（b07231c）。间隙用凸包近似重算，与规划器记录的首个违规点一致（1.50 mm 对 1.49 mm）。进度指把违规状态投影到 Pilz PTP 关节直线上（0 = 脱离终点，100 = 释放点）。

- `summary_table.png` / `summary.json`：每条记录的被拒候选、碰撞对次数、首个违规进度、释放点。
- `cc2546c8_return_collision.png`、`9ec45e42_return_collision.png`：俯视、侧视、斜视和间隙曲线（其余 4 条在现场机 `outputs/return-collision-20261127/`）。
- `return_wrist_flip_and_radius.png`：返回段吸具翻转角和 TCP 水平半径。

要点：
- 所有碰撞都是被抓的箱子本身，不是机械臂或吸具。
- 首个违规在返回段前 0.1–10%，这时箱子刚离开箱垛约 1 cm，离释放点 0.7–1.0 m。
- 首撞时吸具只翻了 0.7–6.5°；25% 时翻到 18–24°，使间隙为 0 一直持续到 30–47%。
- 碰撞对象：多为自身下方的支撑体（下层箱看不到后边界，被延伸成约 1.66 m 宽的一整块），以及侧面的邻箱贴合块。
- 释放点 (−0.073, −0.576, 0.254) 附近间隙有几百毫米，离 −Y 墙 0.13 m 以上，不是问题所在。
- 被抓箱的实测偏航（俯视图中的虚线框）明显偏离机器人轴线，与相机外参残余转角的怀疑一致，等待重新标定后复核。
