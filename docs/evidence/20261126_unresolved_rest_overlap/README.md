# 2026-11-26 原位重叠忽略：没算出支撑也能进入运动规划

用户决定：“只要是某个箱子能看到完整的一个面，即便没恢复出此箱的3维几何，即便没算出该箱是否有支撑，都让该箱能进入运动规划流程”。重叠体积的处理方式选的是“重叠部分都忽略”。

## 现状梳理

- **完整可见面**：单面规则（11-23，代码默认开启）已经能处理只看到正面的箱子，深度按最大 0.2 m 补全。现在仍会被拒绝的只剩正面本身不完整的情况，比如延伸到图像边缘、边缘被遮住。这一条不用改。
- **真正的门槛**：目标包络在原位就和周围物体重叠，或者靠得比间隙要求还近。这时在规划前、候选预检两处都会被拒绝（`GEOMETRY_UNCERTAINTY_*_AT_REST`）。实验表明，就算把这两处拒绝都去掉，路径审计在脱离起点仍会判碰撞。所以碰撞规则不动的话，只拆门槛也规划不出来。

## 规则（`rest_overlap.py`，代码默认开启，配置里写 `mode: DISABLED` 可关闭）

规划某个目标时，对离目标包络不到 3.4 mm 或已经重叠的物体做如下处理。涉及的物体：补出来的体积（邻箱阴影、未解析箱体、未知区域）、实测点、实测支撑面、别的目标的支撑或贴邻。

1. 和目标包络重叠的部分**忽略**，不和任何东西做碰撞检查。
2. 剩下的部分按包络的六个面切开，先底面，再侧面，最后顶面：
   - **底面以下**：作为该目标的支撑（`confirmed_stack_support`，绑定到包络底面）。
   - **侧面以外**：作为贴邻接触（`adjacent_contact`，绑定到该侧面）。
   - 支撑和贴邻都沿用原有规则：只有被抓的箱子、只在脱离段、越过平面不超过 0.4 mm。
   - **顶面以上**：仍是普通障碍，因为脱离时箱子要从那里经过。
   - 没重叠、只是靠得太近的物体，补到贴住那个面为止，只会变大，不会变小。这和原有的贴邻裁切一样，也满足原生端“最高点正好在平面上”的要求。
3. 原有规则已经认作该目标支撑或贴邻的物体，不做任何改动。9707b9cc 第一版就是因为把目标自己的实测支撑又拆了一遍，导致外拉方式规划不出来，所以加了这一条。
4. 不改动的：实测箱体（有自己的贴邻规则）、固定几何、工作空间边界、目标包络本身。机器人和吸具对所有切出来的块都保持完整间隙。
5. 不需要改原生代码。

这是用户给定的现场前提，不是传感器证明那块空间是空的。如果重叠处真有东西，被抓的箱子会碰到它。
