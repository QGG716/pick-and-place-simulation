## 实现

- `src/unloading_sim/workbench/single_carton/vacuum_test.py`（`VacuumBenchTest`）；界面在"视觉单箱任务"页第一行"真空实测…"，打开独立窗口。
- 只用现有 `VacuumOwner` 的占用（claim）和现场配置的 `establish_commands` / `release_commands`（现场为 0x12 抓取货物 / 0x13 释放货物），每次点击、确认后发一条序列。不新增阀门指令，不写阈值，不发传送带指令，机械臂不运动。
- 判定沿用单箱循环的压力门限，阈值未改：阀门发送后的新鲜吸具压力 ≤ grip_below_kpa（−60 kPa）持续 ≥ grip_dwell_s（1 s）即吸附确认；≥ release_above_kpa（−10 kPa）持续 ≥ release_dwell_s（1 s）即释放确认；超时 3 s；压力数据年龄 ≤ 3 s；真空板报警时拒绝。
- 吸附后（不论是否确认）都按"可能持箱"处理：`holding` 一直保持，真空占用仍归本测试，任务、观测和复位都被挡住，直到释放测试确认，或操作员现场确认无负载后人工清除（这一步不发阀门指令，记为 `OPERATOR_CONFIRMED_NO_LOAD`，不算压力证据）。
- 停止（顶栏按钮 / Esc）只调用 `inhibit`：结束等待，不写阀门。之后点"释放测试"，由这次点击重新放开本测试自己的占用。
- 真空被任务占用时不能开始测试（含停止后可能持箱的任务，仍须现场处置）；任务、复位或移动进行中、停止未确认时，也不能开始。
- 吸附确认后，保压监视记录最低、最高、当前压力，以及跌出 hold_below_kpa（−30 kPa）的次数。
- 记录写在 `<record_root>/vacuum_tests/<test_id>/events.jsonl`：开始时的阈值和四路压力表读数、每条阀门帧（hex、发送/返回时间、写入字节数）、每个压力心跳（原始 hex）、门限结果（首次达标和稳定确认相对阀门的时间、极值）、保压丢失、故障和结束。
- 台架结果不是 `PHYSICAL_CYCLE_COMPLETE`，物理循环验收仍为 **NOT_RUN**。

## 现场实测步骤

1. 插上真空板 USB 串口，`ls /dev/ttyUSB*` 确认设备名与现场配置的 `serial_port` 一致（当前为 `/dev/ttyUSB0`）。
2. 正在运行的工作台加载的是旧代码，需由操作员关闭后用新代码重启（同一台机只能有一个程序打开串口）。机械臂停在安全位置；全程不运动。
3. 等"真空：数据有效"。打开"真空实测…"，核对四路表：吸具约 0 kPa，储气罐约 −60，真空泵约 −85，压缩机约 300（文档空闲值），无报警。
4. 空吸测试：吸盘前不放箱子，点"吸附测试"。预期超时（GRIP_PRESSURE_TIMEOUT），看能到的最低压力，用来判断开口泄漏。随后点"释放测试"，预期释放确认。
5. 贴箱测试：手持 2 kg 箱子贴紧吸盘面，点"吸附测试"。预期 1–3 s 内吸附确认。然后保持 10–30 s，观察保压最低值和跌出次数。托住箱子，点"释放测试"，预期释放确认，箱子脱落。
6. 可选：只贴部分吸盘（被动止回）重复第 5 步，比较压力。
7. 每次测试的记录在 `outputs/single_carton/vacuum_tests/` 下，交回后整理成证据。

## 真机后续实测（2026-11-26 13:37–14:15，22 个测试记录）

记录在 `outputs/single_carton/vacuum_tests/vacuum-test-20261126-1337*` 至 `-134703-200`（本地）。

- **气源**：11:49 和 13:37 两次压缩机表约 0 kPa，发 0x12 后吸具压力不动。13:39 起压缩机 180–209 kPa，吸附随即正常。可见吸附需要正压气源。
- **吸附/释放压力**：有气源后吸具达到 −78 到 −82 kPa（≈ 储气罐），一次只到 −64.7 kPa（134614）。阀门后首个达标心跳在 0.02–1.9 s；释放后在 0.3–1.4 s 回到约 −1.7 kPa。保压期间没有一次跌出 −30 kPa。
- **门限误判**：有气源后共 32 次阀门动作，压力全部达标，但现行门限（两次新鲜心跳间隔 ≥ 1 s、3 s 超时）有 9 次判为超时（吸附 5 次、释放 4 次）。原因：真空板心跳约 1 Hz，实测间隔 0.979–1.01 s。两次心跳间隔不足 1.000 s 时要等第三次，加上阀门响应时间就超过 3 s。用记录重放：停留改 0.95 s，或超时改 4 s，32 次全部通过。单箱循环用的是同一门限，会出现同样的误判。门限由用户决定，未改。
- **储气罐泄漏与真空泵**：真空泵会自行停止（11:49 那次在阀门后约 45 s 从 −80 跳到 −2 kPa）。之后储气罐缓慢回升：134703 那次 28 min 内从 −78.6 升到 −22.3 kPa（前 7 min 约 −2.6 kPa/min），泵一直没有重启。吸具最多只能到储气罐压力，储气罐高于 −60 kPa 时吸附必然不达标。泵的启停条件待现场确认。
- **"人工确认无负载"被误用**：有 5 次在吸具仍为 −81 kPa（阀门仍在吸）时点了它（如 134430），随后的吸附测试开始时已经在真空下（134520 首个达标仅 0.02 s，测量无效）。需要加限制：吸具压力仍低于释放门限时拒绝人工清除，开始吸附测试前吸具须已回到释放门限以上。
