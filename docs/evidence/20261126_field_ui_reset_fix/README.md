## 中途停止：J6 未跟随（硬件侧，未改代码）

- 接近段（PTP）共 5066 点，发出 1886 点后，以 `ROBOT_FAILED:TRACKING_ERROR` 停止；停止已确认，未持箱，没有发阀门指令。
- J1–J5 跟踪误差全程不超过 0.25°。J6 指令从 −7.094° 匀速增加到 −4.037°（共 +3.06°，用时 9.4 s），实测 J6 一直停在 −7.07° 到 −7.08°，误差逐步累积到 3.03° 后触发停止。

## 复位回起点没有反应（代码 bug，已修）

- 复位规划两次都通过了（`reset_plan`，return_empty，9.7 s）。确认框点了“确定”以后，`job('reset_done')` 被拒绝，报“操作尚未完成”，所以没有发出运动。
- 原因：规划任务的结束标记排在结果后面才处理。处理结果（弹出确认框）时，规划任务的占用还没释放。11-24 引入复位、11-25 引入“移到观测起点”以来，这两个功能在界面上都没有真正执行过；之前的测试只测了 TaskManager，没测界面。
- 修复：每个后台任务带序号，结束标记只释放自己那一个；确认后由 `confirmed_job` 释放已经返回的规划任务，再启动执行。迟到的旧结束标记不会释放正在执行的复位。
