# ECO65 小箱与仿真独立选杯

本轮接续 `69a90d9791389abcd675428eb52020cc09d9e13a`，按用户新授权采用
`SIMULATED_INDEPENDENT_CUPS`。此前全十二杯模式的不可达结论保留为历史，
不能用于部分杯候选。真实气路字段 `independent_control_verified` 仍为 false。

## 输入和判定

- 十二个物理杯、稳定 ID、完整 CAD 轮廓、实体碰撞、真实法兰和规范 TCP 均保留。
- 候选启用 1–12 杯，所有启用杯须在同一目标、同一面完整密封。封边 3 mm、
  法向 0.01 rad、实际接触间隙/穿透 0.4 mm 保持不变。
- 几何可密封、候选启用和实际 FK 重算集合分开记录。空集合、未知/重复 ID 拒绝；
  目标、面、候选、模型身份和 task ID 绑定到分支，带载时不得换杯。
- 未启用杯保留实体碰撞。终端带只有限定面接触容差，没有邻箱或刚性件豁免。
- 单杯及相邻局部杯组在顶面/正面、八个面内角度上生成有限平移候选，正面增加上缘位置。
  综合杯数、封边、分布、法兰距离和邻箱轮廓点距离提示排序；点距离只作排序，不能验收。
  实际接触 IK、全场景状态检查先于昂贵的预抓取路径。
- 正面接近/撤离沿箱面法向，抽离同时向厢外退出并保持原支撑上方净空。
  实际接触 FK 决定法兰到箱体变换；放置使用这个变换和真实接收面，不移动 TCP。

## 第一组实际布局

配置为 `configs/workcells/eco65_small_carton_v1.yaml`。builder 保留完整仓库、桌架、
侧后板和永久 J1 附件，顶板沿用输入快照已经关闭的状态，不重复转换 STEP。

| 项目 | D 坐标系中的值 |
|---|---|
| 单箱 X/Y/Z | 0.150 / 0.100 / 0.100 m |
| 排/列/层 | 1 / 3 / 4，原十二个 ID |
| 列间隙/层间隙 | 0.010 / 0 m |
| 堆垛深/宽/高 | 0.150 / 0.320 / 0.400 m |
| 两带有效宽度/带面高度 | 0.200 / 0.180 m |
| 初选基座 | [-0.280, 0, 0.180] m，安装座同步移动 |
| 箱堆前沿 | X = 0.130 m，由实际带体外界和 60 mm 间隙重算 |
| 箱体层中心高度 | 0.230 / 0.330 / 0.430 / 0.530 m |

带体、支架、接收区和连接板由锁定输送带 USD 重建；台座、侧后板只保留新的一份。
J1 外壳和安装座沿用验证过的凸分解。实际状态检查发现 J2 整体凸包过度填充后，
从同一官方外壳网格派生 J2 凸分解；后续实际 J3/相机拒绝也发现整体凸包填充间隙，
补充 49 个 J3 凸分块。源网格字节保持不变，规划和 MuJoCo 共用分块，没有新增碰撞豁免。
