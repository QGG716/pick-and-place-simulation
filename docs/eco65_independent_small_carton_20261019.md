# ECO65 小箱与仿真独立选杯

本轮接续 `69a90d9791389abcd675428eb52020cc09d9e13a`，按用户新授权采用
`SIMULATED_INDEPENDENT_CUPS`。此前全十二杯模式的不可达结论保留为历史，
不能用于部分杯候选。真实气路字段 `independent_control_verified` 仍为 false。

## 输入和判定

- 十二个物理杯、稳定 ID、完整 CAD 轮廓、实体碰撞、真实法兰和规范 TCP 均保留。
- 候选启用 1–12 杯，所有启用杯须在同一目标、同一面完整密封。封边 3 mm、
  法向 0.01 rad、实际接触间隙/穿透 0.4 mm 保持不变。
- 几何可密封、候选启用和实际 FK 重算集合分开记录。空集合、未知/重复 ID 拒绝；
  目标、面、候选、模型身份和 task ID 绑定到分支，带载时不得换杯。
- 未启用杯保留实体碰撞。终端带只有限定面接触容差，没有邻箱或刚性件豁免。
- 单杯及相邻局部杯组在顶面/正面、八个面内角度上生成有限平移候选，正面增加上缘位置。
  综合杯数、封边、分布、法兰距离和邻箱轮廓点距离提示排序；点距离只作排序，不能验收。
  实际接触 IK、全场景状态检查先于昂贵的预抓取路径。
- 正面接近/撤离沿箱面法向，抽离同时向厢外退出并保持原支撑上方净空。
  实际接触 FK 决定法兰到箱体变换；放置使用这个变换和真实接收面，不移动 TCP。

## 第一组实际布局

配置为 `configs/workcells/eco65_small_carton_v1.yaml`。builder 保留完整仓库、桌架、
侧后板和永久 J1 附件，顶板沿用输入快照已经关闭的状态，不重复转换 STEP。

| 项目 | D 坐标系中的值 |
|---|---|
| 单箱 X/Y/Z | 0.150 / 0.100 / 0.100 m |
| 排/列/层 | 1 / 3 / 4，原十二个 ID |
| 列间隙/层间隙 | 0.010 / 0 m |
| 堆垛深/宽/高 | 0.150 / 0.320 / 0.400 m |
| 两带有效宽度/带面高度 | 0.200 / 0.180 m |

带体、支架、接收区和连接板由锁定输送带 USD 重建；台座、侧后板只保留新的一份。

补充 49 个 J3 凸分块。源网格字节保持不变，规划和 MuJoCo 共用分块，没有新增碰撞豁免。

## 抽离与转运续跑

`run14` 的第一个正面单杯分支实际通过预抓取 PTP（249.124 s）、接触 LIN
（9.190 s）和外移 47.5 mm / 抬升 10 mm 的抽离 LIN（13.920 s）。此前
160 mm 外移被 IK 拒绝，85 mm / 10 mm 被 J3/相机净空拒绝。三个实际末点
也通过独立 MuJoCo 状态检查；这不是独立全路径通过。

转运 PTP 与邻箱碰撞，三次 20 s OMPL 未完成该分支。`run17` 从明确检查过的
静态近接姿态运行诊断短链，抬升 60 mm / 外移 85 mm 的 LIN 通过；一条实际
OMPL 转运路径被密集 FCL 检查拒绝：目标与左邻箱距离 2.334232 mm，小于
2.4 mm，失败保留于 `extraction_lin_probe02/native_calls.jsonl.gz`。

据此增加有限抽离候选及转运失败后的抽离回退。候选用当前邻箱顶部和原支撑
10 mm 净空计算，本场景为 10 / 60 / 110 mm 抬升，外移 10 / 47.5 / 85 / 160 mm
的十种组合。每次仍运行实际 LIN，并以同一接触末点与选杯身份回退；失败原生
调用保留。短外移不声明完全退出箱垛，转运没有支撑或邻箱豁免。

OMPL 转运搜索对附着箱体的碰撞对增加 0.3 mm 搜索净空；端点与密集输出检查
仍使用原 2.4 mm，工具和箱体尺寸不变。`run18` 的完整 worker `build-small-20261019g`
已重新编译启动，冷启动重跑使用总预算 3600 s、单段求解 60 s、RPC 600 s。
这些是有界搜索参数，不代表该运行已经得到完整计划。

服务器曾在 `run13` 实际报磁盘满。将本轮早期五份大型 JSON 无损压缩，逐份
解压 SHA-256 与原件相等后才回收源字节，释放约 7.5 GB；归档清单为
`small_20261019_log_archival.json`。覆盖表续跑只复用条件快照身份完全相同的
已完成报告，记录原报告路径、哈希和“未重跑”语义。

首轮 `run13` / `run15` 的 24 项覆盖全部返回，11 项原生三段短链通过。
其余项保留接触 IK/碰撞、短段接近或预算原因。`run19` 只复查未完成项，
每面最多 64 候选、每姿态 16 个 IK 种子、240 s；已通过项保留原报告哈希。

首次复查中，底层左箱前吸已从首轮拒绝推进到原生短链通过。
