# Tesseract + OMPL v0.2：固定 FANUC 绕障段原生检查实验

本轮只使用冻结 37 箱场景中的空载 78→208 请求，seed=71070、range=0.18 rad、实际状态计算上限 100000。未启动 Isaac、完整任务、参数扫描或其他分支工作；未重装依赖。基线及原始证据分别见 `validation/evidence/backend_tesseract_ompl_v0_2/baseline.json` 和 v0.1 目录。

## 1. 已知 legacy 路径是否被 native 接受

**接受。** v0.1 comparison.json 保存了完整 29 点路径、固定起终点、seed、场景/模型/工具/策略身份，因此没有重跑 legacy。

本轮当前权威完整边复检通过（350.582 s，31,652 个采样请求、31,625 次实际计算）。优化前审计 worker 用真实 `Context::valid` / `DenseMotion` 接受全部 28 条边、31,639 个原生网格状态。再将这 31,639 个实际 q 原样交给权威逐点检查：**0 个差异、全部完成**，耗时 361.179 s。

最终 worker 同样接受全部 28 条边。按边号和网格索引排序后的实际 q 与优化前逐字节一致，连同原始权威源码不变、场景身份相同，绑定复用了上述逐点权威证据；没有把旧权威计时写成新一轮复检。原始记录见 `baseline-audit/audit.json`、`final-audit-validated/audit.json` 及各自 `native-samples.json.gz`。

## 2. 模型、约束与采样差异

没有发现这条已知路径上的同 q 模型/策略差异，也没有修改几何、净空、奇异性阈值或 IK。

旧 comparison 场景指纹 `1c44147b…` 与当前 `ec7c545c…` 的差别来自 v0.1 后续新增的 `collision_objects` 覆盖清单和 `joints[].type` 元数据。只剔除这两项，重新哈希即精确还原旧指纹；模型、工具、策略指纹均相同。投影只用于核对旧身份，不用于运行或删除几何。

权威网格区间数为 `2*max(1, ceil(Linf/edge_resolution), ceil(4*L1/.0025))`；原生保持原有 `max(1, ceil(L1/.0003125), 2*ceil(Linf/edge_resolution))`。两者满足同一位移上限，但取整产生不同采样位置。审计记录原生实际 q，权威逐点判断，区分同 q 差异、采样位置差异和未完成检查。

合同明确支持固定 `lever_arm_m=4`、`point_motion_bound_m=.00125`，拒绝其他值以及非有限、非正值。角度规则支持 `(0,.055]`。重试采用基准 `.0003125/2**refinement`，最多 refinement=7；Python 与 worker 均验证，worker 返回实际规则。不以缩小杠杆臂制造更粗检查。

## 3. 原生主要耗时

同一已知工程路径、同一既定网格，聚合插桩观测如下（秒）：

| 时钟 | 优化前审计构建 | 最终构建 |
|---|---:|---:|
| FK / 场景状态 | 2.468 | 2.201 |
| Jacobian + SVD | 0.278 | 0.192 |
| 碰撞对象变换更新 | 3.919 | 3.689 |
| FCL contactTest | 79.717 | 72.679 |
| 预算 / 取消轮询 | 0.123 | 0.114 |
| 边调度（不含状态检查） | 0.099* | 0.099 |
| 状态检查，含子时钟 | 87.368 | 79.715 |
| native 总计，含初始化 | 87.672 | 80.034 |

\* 优化前由 edge inclusive 减去状态 inclusive 得到；该路径审计没有边外状态调用，差值可用。最终 worker 直接聚合边内父子时钟差值。

FCL 约占状态检查时间的 91%，是实际主热点。总计单次观测下降约 8.7%，不是无插桩性能或统计加速保证。缓存在此路径只有 27 次命中，不能把该变化归因为大量状态复用。FCL 次序、缓存和环境噪声不能从一次复合修改中拆出独立因果贡献。

全部 profile 使用聚合计数，没有逐状态日志；实际 q 仅在显式审计 trace 中保存，不在工程搜索中逐点输出。独立开销对照在工程请求结束后执行：从已验证网格固定选取 100 个不同状态，统一预热，做两对 off/on（没有搜索）。两对总耗时分别为 237.787→258.047 ms（+8.5%）和 245.987→254.198 ms（+3.3%）。差值包含运行噪声，不能当作已校准的纯时钟开销，也不对规划耗时作减法修正。原先审计脚本附带的小批对照具有缓存清理数量和预热差异，仅保留原始记录，不用于这个估计。

`native_total_s` 包含初始化、检查、搜索等；`edge_check_inclusive_s` 包含状态检查；`state_check_inclusive_s` 包含内部预算轮询、FK、Jacobian/SVD、变换及 FCL。预算轮询也发生于 OMPL 终止条件。父子时钟不可重复相加。边调度单独排除其内部状态检查时间。

## 4. 不放宽规则的优化

- 场景加载时预解析关节名/轴/类型、限位与约束；热循环不再重复读取这些 JSON 字段。复用 Jacobian/SVD 工作区与碰撞结果容器，仍执行相同 FK、Jacobian、奇异性和径向检查。
- 初始化全部对象变换后，每个状态只更新受关节影响的 208 个碰撞对象。47 个静态对象继续参与查询；255 个对象和原 active/filter 列表均保留。
- 请求内 8192 项 FIFO 精确 double 字节缓存；每个调用都清空，因此场景、附着、阶段、策略及细分规则变化必然失效。已知路径 31,639 请求对应 31,612 实际计算、27 命中，不能以近邻状态代替当前 q。额外请求保护为 `32*max_state_checks`，独立于实际计算上限。
- `DenseMotion` 先端点、再中部和逐层二分位置，索引无重复；只有全部 `n+1` 个原网格点完成才通过。不接受只过粗层的边。中断边单列；乱序拒绝时 `lastValid` 保守返回起点，不把未检查的前缀冒充通过。改变的是遇到无效采样点的先后顺序，合法性条件未放宽。
- 真实 native 回归发现并修复了 `ContactResultMap::clear()` 保留空对象对向量导致的非法首条访问。最终遍历到非空条目，场景加载时 release。修复前失败与源码、构建身份保存在 `before-contact-*` 证据中。

对静态更新的核查：[Tesseract 0.35.0 FCL 实现](https://github.com/tesseract-robotics/tesseract/blob/0.35.0/collision/fcl/src/fcl_discrete_managers.cpp) 的 map 批量接口会查找、比较传入的每个对象，姿态不变时已经跳过 BVH 更新。只省去静态对象遍历/比较，不声称消除了原先不存在的大量静态 BVH 重建。

native 返回后，进入 authority 前再次检查取消、场景 revision 和显式墙钟预算；authority 后继续原有检查。这不是硬实时取消保证。

## 5. 同一个工程请求的结果

**仍失败，真实终止为实际状态计算预算耗尽。** 仅运行一次固定工程请求，max_attempts=1；未追加 seed、预算、shortcut 或参数扫描。生成了 approximate 解，关节空间目标残差 **1.038345 rad（L2）**；不是 exact，不交付，也没有启动无意义的候选 authority 复检。

| 结果 / 工作量 | 本轮值 |
|---|---:|
| 实际状态计算 / FCL 查询 | 100000 / 100000 |
| 状态请求 / 缓存命中 | 100223 / 222 |
| 原生网格样本请求 | 100044 |
| 边调用：通过 / 无效 / 未完成 | 223：87 / 135 / 1 |
| OMPL 树节点 / 树边 | 89 / 87 |
| OMPL 迭代数 | null |
| 实际碰撞拒绝状态 / 运动学拒绝状态 | 266 / 0 |
| 预算中断状态请求 | 1（不算碰撞） |
| native 总计 / adapter 请求总计 | 308.046 s / 308.252 s |

工程请求的分项 profile（秒）：FK **6.496**，Jacobian/SVD **0.598**，变换更新 **12.144**，FCL **285.889**，预算/取消轮询 **0.285**，边调度（排除状态）**0.050**。状态检查 inclusive 为 307.779 s，OMPL solve 为 307.824 s；这些父子时钟不可相加。

固定直连边在端点之后的第一个中部网格点即被拒绝，耗时 **0.002606 s**（v0.1 原构建为 20.613 s）。最终 native 中部回归仅需 3 个样本，authority 同 q 同样拒绝工具 `tool_rigid_0` 与 `carton_l05_c03`，5 mm 间隙不足。FCL 给出带符号距离 -5.522 mm，authority 的不相交表面距离在相交时为 0；距离定义不同，判定一致，不称为原始 CAD 穿透证据。

相较 v0.1 的 129 条边，本轮处理到 223 条边，但仍未在预算内连通。v0.1 native 总计约 313.8 s，来自较早、未作本轮分项插桩的构建；两轮不能当作严格等价、无插桩速度实验。

新 `state_requests` 是全部状态检查请求，`state_checks`/实际计算是精确缓存未命中后执行的检查，缓存命中单列。旧 worker 无原生缓存，旧 100000 次计数接近其全部非终止状态请求；本轮至多 100000 次实际计算允许更多请求，不能称为完全等价搜索工作量。OMPL 迭代数保持 null；树节点和 approximate 残差直接来自 OMPL 接口。

## 6. 证据边界

主要未解决成本是通过边所需的大量密集 FCL 查询；本次 100000 次实际计算里仅 266 次碰撞拒绝，缓存命中也很少。快速拒绝避免无效边的长前缀，却不能跳过通过边的必需点。没有足够证据支持更粗网格、近邻缓存、跳点或物理不可达结论。

已知路径的一致性覆盖本场景、本路径及实际采样集合，不是对所有模型状态的全域等价证明。只测一个固定工程请求，没有统计 p50/p95，也不推断完整任务可执行性。有限预算失败不代表物理不可达。v0.1 comparison/full-task 保持原 worker 构建身份，其数据不是本轮最终 worker 的测试结果。


定向验证共 **79 个不同用例通过**：29 个 fake/合同用例、14 个真实 native/已知路径证据用例、36 个直接相关回归。首次综合批次为 76 passed / 2 failed / 1 deferred，真实 native 暴露的容器复用问题修复后重跑 native 13 passed；完整审计完成后，延期的证据用例单独 1 passed。最后补强的中部 authority 对照仍属于原有用例，单独重跑 1 passed，不重复计数。没有整仓测试；fake 不作为 native 集成证据。

覆盖固定合同非法/变更拒绝、实际角度规则改变网格、重试加密、非二次幂完整网格、3 点中部快速拒绝、精确缓存与各类身份失效、预算中断不通过、真实 approximate 不交付、authority 前取消/revision/墙钟拦截，以及完整已知路径证据绑定。测试批次和历史失败见 `test-summary.json` 及对应日志。
