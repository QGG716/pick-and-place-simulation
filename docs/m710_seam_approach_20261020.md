## 几何

横带低位范围 X=[−0.90,−0.20]、Y=[−1.10,1.10] m；纵带 X=[−3.70,−0.90]、Y=[−1.10,−0.40] m。世界坐标由配置与装配变换推导，机器人、底盘、工具及 40 箱尺寸和位置保持。

新版本 `upper_seam_lower_slider_v3` 固定上端 X/Y，Z 跟随横带；低端固定 Z=0.6 m，按固定长度方程沿 X 滑动。低端在 Hmax=2.05 m 时 X=−3.295307914 m，滑移约 404.692 mm。固定导轨采用概念悬臂，支脚位于原有限地面内；滑车和低端轴承移动，固定导轨与支脚不移动。纵带中部支撑为固定地面站位、升降及转动安装头。横带保留 1.25 m 刚性剪叉杆及中央安装件，延长后的顶面含悬臂。

为避免倾斜纵带厚度侵入横带，横带保留完整顶面，底面靠接缝一侧做固定凸多面体斜切。概念几何工作上限为 2.10 m，斜率约 0.634 m/m，120 mm 厚度对应最大底部退让约 76 mm。这不是两带顶面间隙；有效顶面端边保持零缝。相同顶点和面用于显示、原生碰撞与 USD。外包 OBB 仅用于粗筛；接缝必须通过凸实体非穿透检查，未将两条整带列为装配豁免对。

历史配置另存为 `configs/workcells/m710id70_unloading_layout_v1_rear_fixed_20261019.yaml`。无新 coupling 字段的历史入口保持旧后端固定语义，旧轨迹不得和新机构拼接。

18 项新定向测试通过。CPU/原生各检查 593 个同步机构状态，最大高度步长 10 mm，包含双向全行程和三高度保持；旧实体反例及人为接缝穿透被拒绝。机器人和负载检查仍是独立原生规划/诊断门，不能由机构检查替代。

始终保持：`qualification_status=NOT_EVALUATED`、`continuous_swept_proof=false`、`physical_execution=NOT_RUN`、`execution_ready=false`。概念支架未声明承载、驱动或制造资格。

## 预算恢复与直接方法

新连续链明确使用 `recovery_mode="shared_budget"`，不读取 `stage_connection_attempts`，也不传 `max_ompl_attempts`。旧公共 API 的 `legacy_quota` 模式保留兼容语义；与新模式混用次数参数会被拒绝。每个连接时间片最多 6 s，原生 RRT 请求分配不超过 2 s，时间片内按剩余时间继续请求，不按发生过多少次停止。全部时间片、IK、后置检查仍使用同一任务及阶段绝对期限。新请求记录 `RESTART / tree_retained=false`；既有 4096 项输入资源保护保留。

仅空载 `pregrasp / FREE_APPROACH` 开放新 PTP/LIN 偏好。每种直连的求解时间不超过连接时间片的 10% 且最多 0.75 s，其余机会留给 RRT。原生端仍检查起始零速、真实 parent receipt、模型、世界、机器人/工具碰撞。PTP 不是 TCP 直线；LIN 使用原生任务 TCP 目标，不生成 Python 插值轨迹。

合法 q 保留在本地池中。为枚举不同 IK 而暂时传入已知 q，不等于从运动恢复池删除它；只有明确非法端点才被排除。排序先考虑已消耗的求解时间与后缀失败历史，再用六轴等权、不取模的关节行程。整圈替代表示仅在官方有限关节范围内、全部连杆 FK 相同后保留，原表示不删除。可行前段尚未绑定后缀时，明显绕行可用少量剩余预算尝试已有构型；失败或未改善时保留原生可行结果。

完整计划、请求、搜索记录、连接指标及检查点先落盘，之后才更新批次完成状态。请求级错误不再被广义异常吞掉后继续下一箱。注入磁盘写入失败的定向测试确认原完成状态不变。

额外原生反例实测确认：MoveIt 三角表面检查未检测到完全包围的小盒，而同顶点的闭合凸实体检查正确拒绝。新端部的原生检查因此绑定经过顶点/面一致性核验的 FCL 凸实体；显示与 ROS 世界仍使用同一边界网格。缺少绑定、几何改变和非平面面片均失败关闭。它没有扩大或缩小实际几何。
