## 预算恢复与直接方法

新连续链明确使用 `recovery_mode="shared_budget"`，不读取 `stage_connection_attempts`，也不传 `max_ompl_attempts`。旧公共 API 的 `legacy_quota` 模式保留兼容语义；与新模式混用次数参数会被拒绝。每个连接时间片最多 6 s，原生 RRT 请求分配不超过 2 s，时间片内按剩余时间继续请求，不按发生过多少次停止。全部时间片、IK、后置检查仍使用同一任务及阶段绝对期限。新请求记录 `RESTART / tree_retained=false`；既有 4096 项输入资源保护保留。

仅空载 `pregrasp / FREE_APPROACH` 开放新 PTP/LIN 偏好。每种直连的求解时间不超过连接时间片的 10% 且最多 0.75 s，其余机会留给 RRT。原生端仍检查起始零速、真实 parent receipt、模型、世界、机器人/工具碰撞。PTP 不是 TCP 直线；LIN 使用原生任务 TCP 目标，不生成 Python 插值轨迹。

合法 q 保留在本地池中。为枚举不同 IK 而暂时传入已知 q，不等于从运动恢复池删除它；只有明确非法端点才被排除。排序先考虑已消耗的求解时间与后缀失败历史，再用六轴等权、不取模的关节行程。整圈替代表示仅在官方有限关节范围内、全部连杆 FK 相同后保留，原表示不删除。可行前段尚未绑定后缀时，明显绕行可用少量剩余预算尝试已有构型；失败或未改善时保留原生可行结果。

完整计划、请求、搜索记录、连接指标及检查点先落盘，之后才更新批次完成状态。请求级错误不再被广义异常吞掉后继续下一箱。注入磁盘写入失败的定向测试确认原完成状态不变。
