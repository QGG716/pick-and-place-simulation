# S50 同轴法兰隔距段

本轮用户授权的运动学安装方案：保留已生成的 105 mm 短支架，在 S50 法兰和短支架的宽安装板之间加入 80 mm 同轴刚性隔距段。

- 隔距段按理想圆柱建模，直径 118 mm，取自 S50 法兰 CAD 本体的横向尺寸；可视网格与碰撞网格使用同一份数据。
- 法兰到吸具背板后平面：185 mm。法兰到名义压缩吸盘接触面：252.5 mm。
- 原有 200 mm 延长段仍移除；原吸具的固有变换及 72 个吸盘不变。FANUC 安装配置不受影响。
- 原来的 3 个短支架零件保持原 CAD 网格和相对位置。只新增 `tool_s50_mount_spacer`，没有平移机器人、箱堆或传送带。
- 这是明确的仿真假定，尚非安装螺孔、强度、质量或惯量的制造证明。

生成命令：`python tools/prepare_s50_flange_spacer.py --length .08`。
配置：`configs/robots/huayan_s50_spacer80_kinematic_sim.yaml`。
