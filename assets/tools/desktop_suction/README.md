# 真实小吸具 STEP 投放说明

唯一投放目录：`assets/tools/desktop_suction/cad/raw/`。
直接复制已有 `.step` 或 `.stp`，保留原文件名；支持中文、空格和大小写扩展名，无需转换。
装配总成、转接板和相关原件可以一起放入，保留原文件夹关系。

raw 是原件目录，后续转换、简化、修复、网格化不得覆盖原件。
meshes/collision 本轮只建空目录，不生成任何模型。三目录的资产默认仅在本地保存；
Git 仅跟踪占位及说明，不自动公开原件或派生文件。

质量、材质、TCP、法兰关系、吸盘数量、真空气路均 unknown/null，有 STEP 不代表这些属性已知。
本轮不解析 STEP、不网格化、不拟合 OBB、不推断安装姿态、不生成碰撞模型。
如文件已放入，也仅报告“文件已存在但未处理”。
不建立文件监听、后台任务或自动继续机制；下一轮须用户明确指示继续。
