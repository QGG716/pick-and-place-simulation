# 桌面吸具：本地私有 CAD

原件位于 `cad/raw/`，递归识别 `.step/.stp`，保留大小写、中文、空格和原始文件名。原件只读，转换脚本不回写、不重命名、不删除。当前实际总成含 36 个有效实体、12 个吸附组件。

`derived/visual/` 保存真实 CAD 网格，`derived/collision/` 保存逐零件凸体及工作面分区，`derived/manifests/cad.json` 保存单位、装配实例变换、拓扑、颜色、尺寸和源 SHA-256。上述文件均被 Git 忽略；旧 `meshes/`、`collision/` 占位保留。

`configs/local/eco65_desktop/tool.json` 保存完整安装变换链、TCP、全部吸附轮廓、几何映射和明确的仿真转接件。实际质量、材质、压缩特性、气路和安装均未实测；不推断独立气路。转换只支持本轮已经检查的毫米装配结构；不同单位或多个候选文件会明确拒绝自动选择。

使用方法与结果见 [第一轮报告](../../../docs/eco65_desktop_round1.md)。资产不上传、不推送；没有目录监听或自动执行真机的入口。
